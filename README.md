# PipEdit

Экспериментальный редактор кода из экосистемы Pip.

## Цели

- быстрый и удобный редактор кода;
- проекты и файловая структура;
- расширения;
- терминал и инструменты разработки;
- интеграция с другими проектами Pip/Pipis.

## Структура

- `app/` — приложение и UI
- `core/` — общая логика редактора
- `extensions/` — система расширений
- `terminal/` — терминальные инструменты
- `themes/` — темы оформления
- `docs/` — документация

PipEdit является отдельным проектом. Он не должен зависеть от PipOS.
