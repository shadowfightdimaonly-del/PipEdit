# Архитектура PipEdit

PipEdit строится модульно, чтобы редактор можно было расширять без превращения проекта в монолит.

## Слои

1. `app/` — запуск приложения и пользовательский интерфейс.
2. `core/` — документы, вкладки, настройки и общие модели.
3. `extensions/` — API и загрузка расширений.
4. `terminal/` — выполнение команд и взаимодействие с инструментами.
5. `themes/` — оформление редактора.

## Принцип

Сначала рабочий минимальный редактор, затем расширения и дополнительные возможности. Не пытаемся построить VS Code за один вечер, потому что человечество уже совершало эту ошибку.
