# Pip / Pipis ecosystem

PipEdit является частью общей экосистемы Pip/Pipis.

В будущем приложения экосистемы могут содержать единый раздел или каталог со ссылками на другие официальные проекты.

Важно: ссылки на проекты добавляются по мере появления стабильных адресов, а не хардкодятся заранее во все приложения.

## Именование

Текущее рабочее название экосистемы: Pip/Pipis.

Firebase-проект Pipisgram использует идентификатор `pipisgram-afc20`; это технический идентификатор Firebase и не обязан совпадать с публичным названием компании или бренда.
